# 需求修改记录（2026-03-13）

## 一、修改项清单

### 1. 经办人导出为姓名

**问题**：工程项目清单及台账导出 Excel 后，「经办人」列显示为数字（user_id），应显示为经办人姓名。

**涉及**：
- 工程项目清单导出：`/api/projects/export/excel`，`procurement_officers` 当前直接写入
- 台账导出：`/api/ledger/export/excel`，`officer` 字段

**实现要求**：导出前将经办人 ID 解析为姓名（real_name 或 username），多选时用换行或逗号分隔。

---

### 2. 采购项目总览 - 中标列同步

**问题**：采购项目总览弹窗中，供应商信息的「中标」列不随供应商信息变更而同步更新。

**涉及**：`ProcurementListView.vue` 总览弹窗、`getProcurement` 返回的 `suppliers`、`is_winner` 字段。

**实现要求**：当用户编辑供应商（含报价、排名等）并保存后，中标人应根据最新规则重新计算（如按报价升序取第一名），总览中的「中标」列需反映最新结果。

---

### 3. 金额保留两位小数

**问题**：以下列需保留两位小数，末位为 0 也需保留（如 100.00）。

**涉及列**：
| 页面 | 列名 |
|------|------|
| 工程项目清单 | 总包合同价 |
| 采购项目清单 | 控制价 |
| 台账 | 控制价、合同价 |

**实现要求**：展示与导出均使用两位小数格式（如 `100.00`、`99.50`）。

---

### 4. 归档文件 - 移除打印方式

**问题**：「归档文件」列表中仍有「打印方式」列，需移除。

**涉及**：
- 采购项目清单页 → 归档文件 Tab：`ProcurementListView.vue`
- 归档管理页：`ArchiveView.vue`

**实现要求**：移除「打印方式」列及相关的 `print_mode` 下拉、`updateFilePrintMode` 调用。后端 `print_mode` 字段可保留（兼容旧数据），前端不再展示和编辑。

---

### 5. 台账排序规则

**问题**：台账项需按「项目编号」分组，同一编号放一起；组内顺序：材 → 设备 → 机械，补充协议跟随主合同。

**示例**：
```
1. 专机25-01N-材1
2. 专机25-01N-材1-补1
3. 专机25-01N-材1-补2
4. 专机25-01N-材2
5. 专机25-01N-设备1
6. 专机25-01N-机械1
```

**已确认**（2026-03-13）：
- 「项目编号」指台账表格中的「项目编号」列（如 10250019JZ），即 Ledger.project_number / 同一工程
- 同一项目编号下，按采购类型固定优先级：材（材料采购）→ 设备（设备采购）→ 机械（机械租赁）
- 补充协议紧跟主合同：主合同 材1 后紧跟 材1-补1、材1-补2，再排 材2

**实现要求**：台账列表（含分页、导出顺序）按上述规则排序。
