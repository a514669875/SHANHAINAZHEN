## 二、发现的问题（按类别）

### 2.1 数据不同步 / 文件系统不一致

| 编号 | 严重程度 | 描述 | 位置 | 复现步骤 |
|------|----------|------|------|----------|
| **D1** | 高 | **草稿采购的流程文件无法查看**：`/api/files/process-list`、`process-content`、`delete/process-file` 计算文件夹时使用 `工程编号-草稿`，但草稿实际文件夹为 `工程编号-草稿X`，导致找不到文件 | `backend/app/api/files.py` 第 55-61、88-93、117-122 行 | 选择草稿采购项目 → 流程文件标签 → 列表为空或预览/删除失败 |
| **D2** | 中 | 项目/采购重命名失败时异常被 `except: pass` 吞掉，用户无感知，DB 与文件夹可能不一致 | `procurements.py`、`projects.py` | 编辑项目/采购修改名称 → 若文件夹重命名失败，无错误提示 |
| **D3** | 中 | 五选二删除时 `delete_procurement_resources` 对两个 procurement 各执行一次，会两次尝试删除同一流程文件夹，第二次可能抛错（被忽略） | `procurements.py` 删除逻辑 | 删除五选二采购项目 |
| **D4** | 低 | 归档后 `_temp/{project_id}/{procurement_id}/` 可能留下空目录，未清理 | `archive_service.py` | 上传合同文件并完成归档后 |

### 2.2 表格 / 列表刷新

| 编号 | 严重程度 | 描述 | 位置 |
|------|----------|------|------|
| **T1** | 中 | 归档管理切换采购项目后，若 `loadFiles` 与 `loadArchiveStatus` 请求顺序或竞态处理不当，可能短暂显示错误状态 | `ArchiveView.vue` |
| **T2** | 低 | 采购项目清单在批量删除后，若 `selectedProcurementForFiles` 指向已删除项，流程文件区域可能显示异常 | `ProcurementListView.vue` |

### 2.3 逻辑错误 / 边界

| 编号 | 严重程度 | 描述 | 位置 |
|------|----------|------|------|
| **L1** | 中 | 补充协议草稿完成时，`parent_contracts` 包含当前记录，`len(parent_contracts)` 作为补序号；若存在并发创建，可能重复编号 | `procurements.py` update_procurement |
| **L2** | 低 | `get_next_contract_seq` 遍历所有 procurement 解析编号，数据量大时可能较慢 | `procurement_service.py` |
| **L3** | 低 | 采购内容含 `/`、`\` 等字符时，文件夹路径可能异常 | `procurement_service.py` |
| **L4** | 低 | 五选二在采购清单仅显示一标段一行，`contract_price` 为一标段金额，PRD 未明确是否需展示两标段合计 | `procurements.py` list |

### 2.4 错误处理与用户体验

| 编号 | 严重程度 | 描述 | 位置 |
|------|----------|------|------|
| **E1** | 中 | 多处 `except Exception: pass` 吞掉错误，用户无法感知失败原因（Word 生成、文件夹重命名等） | `procurements.py`、`projects.py` |
| **E2** | 低 | 非经办人访问时返回 403，未区分「无权限」与「资源不存在」 | 各 API |
| **E3** | 低 | 模板目录不存在或为空时，创建采购项目不生成 Word 文件，无提示 | `procurements.py` |

### 2.5 缺失或待确认功能

| 编号 | 描述 |
|------|------|
| **M1** | 流程文件「编辑」：当前仅有预览/下载，无在线编辑或版本管理 |
| **M2** | 项目删除时，`_temp` 下该项目的临时文件未显式清理 |
| **M3** | 工程项目导出：需勾选才能导出，未勾选时提示；与 PRD 8.12 一致 |
| **M4** | 智能台账导出：需勾选才能导出，逻辑与项目导出类似 |

## 四、需与您确认的问题

### 4.1 业务规则

1. **五选二采购清单展示**：当前只显示一标段一行，`contract_price` 为一标段金额。是否需要展示两标段合计，或单独列出一/二标段？

2. **项目类型与模板**：`project_type` 为「集团内项目」「集团外项目」，模板目录为「集团内工程」「集团外工程」。是否所有使用处都已正确映射？

3. **自有资金项目**：`project_type` 为空时，模板路径为三级（无集团内/外）。是否与业务规则一致？

4. **流程文件「编辑」**：当前流程文件仅有预览、删除。是否需要支持在线编辑或打开本地 Word？

### 4.2 技术决策

5. **临时目录清理**：归档后是否需要在后台定期清理 `_temp` 空目录？

6. **错误提示**：是否希望将 `except: pass` 改为记录日志并向前端返回明确错误信息？

7. **D1 修复优先级**：草稿流程文件无法查看（files API 未适配 草稿X）是否需优先修复？
