# 开发系统修改计划 V2

## 一、修改原则

- **修改前**：阅读 PRD/UI 文档中对应章节
- **修改后**：再次阅读文档校验是否满足要求

## 二、分项修改计划

### 1. 采购项目清单页：编辑、搜索、上下分区

**文档依据**：[UI.md 3.2.3](PRDs/UI.md) (212-327)


| 修改点   | 实施要点                                                                                      |
| ----- | ----------------------------------------------------------------------------------------- |
| 编辑按钮  | 在操作栏增加 [编辑] 按钮；支持编辑选中采购项，打开四步式表单弹窗                                                        |
| 搜索框   | 页面右上角增加搜索框（240px 宽），支持按采购项目名称、合同编号、供应商等模糊搜索                                               |
| 上下分区  | 上区域：采购项目清单表格；可拖拽分隔线（使用 `el-split` 或 `resize` 实现）；下区域：流程文件 / 归档文件 两个页签                     |
| 下区域页签 | 流程文件页签：展示当前选中采购项目的流程文件列表；归档文件页签：展示归档文件列表；[上传] 按钮可跳转至归档管理页并携带 project_id、procurement_id 参数 |
| 下区域功能 | 上传、删除、编辑、打印、分页；打印方式单面/双面下拉                                                                |


**涉及文件**：[ProcurementListView.vue](frontend/src/views/project/ProcurementListView.vue)、[router/index.ts](frontend/src/router/index.ts)

---

### 2. 项目信息页：补充日期字段与五选二字段

**文档依据**：[PRD.md 3.2.4](PRDs/PRD.md) (179-195)、[UI.md 3.2.2](PRDs/UI.md) (353-384)


| 字段         | 输入格式                |
| ---------- | ------------------- |
| 公告日期       | 年/月/日 三个文本输入框       |
| 意向报名截止日期   | 年/月/日 三个文本输入框       |
| 交易文件封面年月   | **年/月** 两个文本输入框（无日） |
| 交易文件日期     | 年/月/日 三个文本输入框       |
| 交易文件获取截止日期 | 年/月/日 三个文本输入框       |
| 响应文件递交截止日期 | 年/月/日 三个文本输入框       |
| 合同签订时间     | 年/月/日 三个文本输入框       |


**五选二模式**（[PRD 198-204](PRDs/PRD.md)）：在「采购项目名称」下增加「一标段名」「二标段名」；在「控制价」下增加「控制价标1」「控制价标2」。

**涉及文件**：[ProcurementListView.vue](frontend/src/views/project/ProcurementListView.vue)、[procurements.py](backend/app/api/procurements.py)、[procurement_service.py](backend/app/services/procurement_service.py)

### 3. 流程时间页：改为文本输入

**文档依据**：[PRD.md 3.2.6](PRDs/PRD.md) (248-266)

- 16 个流程节点的日期列：使用 `el-input` 文本输入框，不使用 `el-date-picker`
- 用户直接输入日期文本（如 2026-03-15）

**涉及文件**：[ProcurementListView.vue](frontend/src/views/project/ProcurementListView.vue)

---

### 4. 暂存功能

**文档依据**：[PRD.md 3.3.5](PRDs/PRD.md) (369-370)

- 新增采购弹窗底部增加 [暂存] 按钮（与 [下一步] 并列）
- 点击暂存：无论表单是否填写完整，均保存当前数据并**立即生成采购项目专属文件夹及全套流程文件**（文件内容可保留模板/占位符）
- 暂存后不关闭弹窗，用户可继续填写；或关闭后下次打开时恢复
- 需新增后端接口：`POST /procurements/draft` 或扩展 create 支持 `is_draft=true`

**涉及文件**：[ProcurementListView.vue](frontend/src/views/project/ProcurementListView.vue)、[procurements.py](backend/app/api/procurements.py)、[procurement_service.py](backend/app/services/procurement_service.py)、[word_service.py](backend/app/services/word_service.py)

### 5. 归档管理：工程/采购项目选择后显示内容

**文档依据**：[UI.md 3.3.1](PRDs/UI.md) (551-558)

- 工程选择：选择后选择框内**必须显示**所选工程名称（如「专机26-01N 厂房扩建」）
- 采购项目选择：选择后选择框内**必须显示**所选采购项目名称（如「专机26-01N-材1 混凝土材料」）
- 检查 `el-option` 的 `label` 是否正确；`v-model` 绑定 `id` 时，需确保选中后能正确回显 label（Element Plus 默认支持，若为空需排查数据或 `value-key`）

**涉及文件**：[ArchiveView.vue](frontend/src/views/archive/ArchiveView.vue)

---

### 6. 归档页面：「此文件为合同文件」达到规定数量时禁用

**文档依据**：[UI.md 3.3.1](PRDs/UI.md) (538-539)

- 普通主合同/补充协议：已上传 1 份合同文件时，勾选框禁用
- 五选二：已上传 2 份合同文件时，勾选框禁用
- 当前实现已有 `:disabled="archiveStatus?.uploaded >= archiveStatus?.required"`，需确认逻辑正确且 `archiveStatus` 及时更新

**涉及文件**：[ArchiveView.vue](frontend/src/views/archive/ArchiveView.vue)

---

### 7. 面包屑导航：遍历所有路径

**文档依据**：[UI.md 3.5](PRDs/UI.md) (655-678)

目标路径示例：


| 路径                           | 面包屑                                            |
| ---------------------------- | ---------------------------------------------- |
| `/`                          | 首页                                             |
| `/projects`                  | 首页 → 工程项目业务管理 → 工程项目清单                         |
| `/projects/:id/procurements` | 首页 → 工程项目业务管理 → 采购项目 → {工程编号} → 采购项目清单         |
| 新增采购弹窗打开时                    | 首页 → 工程项目业务管理 → 采购项目 → {工程编号} → 新增采购项目         |
| 选中采购项+流程文件页签                 | 首页 → 工程项目业务管理 → 采购项目 → {工程编号} → {采购项目名} → 流程文件 |
| `/archive`                   | 首页 → 归档管理                                      |
| 归档+选中工程+采购项目                 | 首页 → 归档管理 → {工程编号} → {采购项目名} → 上传合同文件          |
| `/ledger`                    | 首页 → 智能台账                                      |
| 台账详情（若有）                     | 首页 → 智能台账 → 合同详情 → {合同编号}                      |
| `/settings`                  | 首页 → 系统设置                                      |


**涉及文件**：[MainLayout.vue](frontend/src/layouts/MainLayout.vue)、[router/index.ts](frontend/src/router/index.ts)；需通过 `route.params`、`route.query` 或全局状态获取工程/采购项目名称以填充面包屑

### 8. 自有资金：模板路径

**文档依据**：[UI.md 3.2.4.1](PRDs/UI.md) (348-349)、[PRD 3.1.2](PRDs/PRD.md)

- 资金类别=自有资金时：不区分集团内/外
- 模板路径：`自有资金 / 材料（设备）采购或机械租赁 / 采购方式`（三级，无集团内/外）
- [word_service.py](backend/app/services/word_service.py) 中 `get_template_path` 已实现该逻辑（约 40-43 行），需确认与 PRD 一致；若模板目录结构不符，需调整

### 9. 全局字体增大一号、表格行高、弹框尺寸

**文档依据**：[UI.md 2.2](PRDs/UI.md) (36-45)、[UI.md 4.2](PRDs/UI.md) (693-704)、[UI.md 4.6](PRDs/UI.md) (729-733)


| 修改点  | 实施要点                                                              |
| ---- | ----------------------------------------------------------------- |
| 字体   | 全局 CSS 变量或 `:root` 中 base-font-size 增大 1px（如 13px→14px，14px→15px） |
| 表格行高 | 从 40px 调整为约 44-48px，与字体协调                                         |
| 弹框尺寸 | 所有 `el-dialog` 的 `width` 适当增大（如 800→880，720→800）                  |
| 弹窗遮罩 | 保持 `:close-on-click-modal="false"`                                |


**涉及文件**：全局样式、各 Vue 页面中的 `el-dialog`、`el-table`
